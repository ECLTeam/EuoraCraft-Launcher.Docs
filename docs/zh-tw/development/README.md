## 專案介紹

歡迎來到 ==EuoraCraft Launcher== 的開發者文件！本專案是一個開源的 Minecraft 啟動器，旨在為玩家提供更好的遊戲體驗與更多自訂選項。無論您想貢獻程式碼、修正錯誤，還是新增功能，這裡都是您的起點。

本專案主要是以 `PyTauri` 與 `vue3` 開發的跨平台桌面應用程式，支援 Windows、Linux 與 macOS。我們歡迎所有對 Minecraft 啟動器開發有興趣的開發者加入社群，一起打造更好的遊戲體驗。

如果您對 Minecraft 啟動器的通用原理有興趣，可以閱讀[技術教學](/zh-tw/tutorials/minecraft-launcher/)；這裡的內容則聚焦於 EuoraCraft Launcher 本身的開發與貢獻。

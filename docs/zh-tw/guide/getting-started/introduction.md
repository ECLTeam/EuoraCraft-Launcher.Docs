==EuoraCraft Launcher==（ECL）是一個面向 Minecraft 的**第三方開源啟動器**。它可以透過**外掛**擴充啟動器功能，打造符合您需求的啟動器。

本專案的目標是為 Minecraft 玩家提供一個**輕量、易用、可擴充**的啟動器，支援多帳號、多執行個體、多模組組合，並提供連線房間功能。

## 你可以用 ECL 做什麼？

本啟動器以==外掛==作為主要功能，旨在提升使用體驗；在擴充之外，啟動器原生支援以下功能：

:::: steps
1. 多帳號管理

   你可以在啟動器中新增==多個帳號==，並在不同帳號之間切換，支援 **Microsoft**、**離線帳號**、**外置登入** 帳號登入。

2. 多執行個體管理

    你可以在啟動器中建立多個執行個體，並在==不同執行個體==之間切換。每個執行個體可以獨立設定**遊戲版本**、**模組**、**資源包**等。

3. 模組管理

    你可以在啟動器中**安裝**、**解除安裝**、**更新**模組，並支援模組的相依性管理。啟動器內建模組==線上搜尋==功能，方便尋找與下載模組。

4. 連線

    你可以在啟動器中==建立==連線房間，邀請好友加入；也可以==加入==其他玩家**建立**的房間，體驗多人連線的樂趣。

5. 資源管理

    你可以在啟動器中==管理==遊戲的**資源包**、**材質包**、**光影包**等，並支援資源的**匯入**與**匯出**。你也可以在啟動器中檢視遊戲的**日誌**與**崩潰報告**，方便排查問題。

::::

## 開始使用

在使用 ==EuoraCraft Launcher== 之前，您需要閱讀[使用者條款](/zh-tw/guide/user-agreement/)，並確認您的系統是否**支援**。

目前 **ECL** 僅支援以下系統與版本：

- Windows 10 及以上版本
- macOS 10.15 及以上版本[+macosversion]
- Linux（Ubuntu 20.04 及以上版本）

[+macosversion]:
  目前 **ECL** 尚未在 **macOS** 系統上測試，可能存在相容性問題。

如果您確認系統符合要求，請前往 [EuoraCraft Launcher GitHub Releases](https://github.com/ECLTeam/EuoraCraft-Launcher/releases) 下載最新版本的啟動器。

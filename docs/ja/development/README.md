## プロジェクトについて

==EuoraCraft Launcher== の開発者向けドキュメントへようこそ。本プロジェクトは、プレイヤーにより良いゲーム体験と多くのカスタマイズ手段を提供することを目的とした、オープンソースの Minecraft ランチャーです。コードの貢献、不具合の修正、新機能の追加など、ここが出発点になります。

本プロジェクトは主に `PyTauri` と `vue3` で開発されたクロスプラットフォームのデスクトップアプリケーションで、Windows、Linux、macOS に対応しています。Minecraft ランチャーの開発に関心のある開発者の参加を歓迎します。

Minecraft ランチャー全般の仕組みに興味がある場合は[チュートリアル](/ja/tutorials/minecraft-launcher/)を参照してください。ここでは EuoraCraft Launcher 自体の開発と貢献に焦点を当てます。

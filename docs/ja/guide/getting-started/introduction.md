==EuoraCraft Launcher==（ECL）は Minecraft 向けの**サードパーティ製オープンソースランチャー**です。**プラグイン**で機能を拡張でき、用途に合わせたランチャーに仕上げられます。

本プロジェクトの目標は、Minecraft プレイヤーに**軽量・使いやすい・拡張可能**なランチャーを提供することです。複数アカウント、複数インスタンス、複数の Mod 構成に対応し、マルチプレイルーム機能も提供します。

[**EuoraCraft Launcher 公式サイト**を見る](https://www.eclteam.top/){.read-more}

## ECL でできること

本ランチャーは==プラグイン==を主な機能拡張手段とし、使い勝手の向上を目指しています。拡張とは別に、次の機能を標準で備えています：

:::: steps
1. 複数アカウントの管理

   ==複数のアカウント==を追加し、切り替えられます。**Microsoft**、**オフラインアカウント**、**外部ログイン**に対応します。

2. 複数インスタンスの管理

   複数のインスタンスを作成し、==インスタンス間==を切り替えられます。各インスタンスで**ゲームバージョン**、**Mod**、**リソースパック**などを個別に設定できます。

3. Mod の管理

   Mod の**インストール**、**アンインストール**、**更新**ができ、依存関係の管理にも対応します。==オンライン検索==機能を内蔵し、Mod の検索とダウンロードが簡単です。

4. マルチプレイ

   ==ルームを作成==してフレンドを招待できます。ほかのプレイヤーが**作成**したルームに==参加==して多人数プレイを楽しむこともできます。

5. リソースの管理

   ゲームの**リソースパック**、**テクスチャパック**、**シェーダーパック**などを==管理==でき、**インポート**と**エクスポート**に対応します。**ログ**や**クラッシュレポート**も確認でき、問題の切り分けに役立ちます。

::::

## はじめかた

==EuoraCraft Launcher== を使う前に、[利用規約](/ja/guide/user-agreement/)を読み、お使いのシステムが**対応**しているか確認してください。

現在の **ECL** が対応するシステムとバージョンは次のとおりです：

- Windows 10 以降
- macOS 10.15 以降[+macosversion]
- Linux（Ubuntu 20.04 以降）

[+macosversion]:
  現在 **ECL** は **macOS** での動作確認を行っていないため、互換性の問題が発生する可能性があります。

システムが要件を満たしている場合は、[EuoraCraft Launcher GitHub Releases](https://github.com/ECLTeam/EuoraCraft-Launcher/releases) から最新版をダウンロードしてください。

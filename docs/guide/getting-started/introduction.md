==EuoraCraft Launcher==（ECL）是一个面向 Minecraft 的**第三方开源启动器**。它可以通过**插件**来拓展启动器的功能，能够定制出符合您需求的启动器。

本项目的目标是为 Minecraft 玩家提供一个**轻量、易用、可扩展**的启动器，支持多账户、多实例、多模组组合，并提供联机房间功能。

## 你可以用 ECL 做什么？

本启动器以==插件==作为主要功能，旨在提高用户的使用体验，在拓展之外，启动器原生支持以下功能：

:::: steps
1. 多账户管理

   你可以在启动器中添加==多个账户==，并在不同账户之间切换。并支持 **Microsoft** , **离线账户**, **外置登录** 账户登录。

2. 多实例管理

    你可以在启动器中创建多个实例，并在==不同实例==之间切换。每个实例可以独立配置**游戏版本**、**模组**、**资源包**等。

3. 模组管理

    你可以在启动器中**安装**、**卸载**、**更新**模组，并支持模组的依赖管理。启动器内置了模组==在线搜索==功能，方便你查找和下载模组。

4. 联机

    你可以在启动器中==创建==联机房间，邀请好友加入。你也可以==加入==其他玩家**创建**的房间，体验多人联机的乐趣。

5. 资源管理

    你可以在启动器中==管理==游戏的**资源包**、**材质包**、**光影包**等，并支持资源的**导入**和**导出**。你也可以在启动器中查看游戏的**日志**和**崩溃报告**，方便你排查问题。

::::

## 开始使用

在使用 ==EuoraCraft Launcher== 之前，您需要阅读[用户协议](/guide/user-agreement/)同意并确认您的系统是否**支持**。

当前**ECL**仅支持以下的系统和版本：

- Windows 10 及以上版本
- MacOS 10.15 及以上版本[+macosversion]
- Linux(Ubuntu 20.04 及以上版本)

[+macosversion]:
  当前 **ECL** 未在 **MacOS** 系统上进行过测试，可能存在兼容性问题。

如果您确定您的系统符合要求，请前往 [EuoraCraft Launcher GitHub Releases](https://github.com/ECLTeam/EuoraCraft-Launcher/releases) 下载最新版本的启动器。

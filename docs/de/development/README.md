## Über das Projekt

Willkommen in der Entwicklerdokumentation von ==EuoraCraft Launcher==! Das Projekt ist ein Open-Source-Launcher für Minecraft mit dem Ziel, Spielern eine bessere Erfahrung und mehr Anpassungsmöglichkeiten zu bieten. Ob du Code beitragen, Fehler beheben oder Funktionen ergänzen möchtest – hier beginnst du.

Das Projekt ist überwiegend mit `PyTauri` und `vue3` als plattformübergreifende Desktop-Anwendung für Windows, Linux und macOS umgesetzt. Wir freuen uns über alle, die sich für die Entwicklung von Minecraft-Launchern interessieren.

Wenn dich die allgemeinen Grundlagen von Minecraft-Launchern interessieren, lies die [Tutorials](/de/tutorials/minecraft-launcher/); hier geht es um die Entwicklung von EuoraCraft Launcher selbst.

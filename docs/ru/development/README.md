## О проекте

Добро пожаловать в документацию для разработчиков ==EuoraCraft Launcher==! Проект представляет собой лаунчер Minecraft с открытым исходным кодом, цель которого — дать игрокам более удобный опыт и больше возможностей настройки. Если вы хотите помогать с кодом, исправлять ошибки или добавлять функции — начните отсюда.

Проект в основном разработан на `PyTauri` и `vue3`: это кроссплатформенное настольное приложение для Windows, Linux и macOS. Мы рады всем, кому интересна разработка лаунчеров Minecraft.

Если вам интересны общие принципы работы лаунчеров Minecraft, читайте [руководства](/ru/tutorials/minecraft-launcher/); здесь же речь идёт о разработке и участии в самом EuoraCraft Launcher.
